When the Old File Sounds Reasonable

The old file will visit today wearing reasonable clothing. It will tell you to slow down, ease up, be gentle, that you are being too intense. That is the old character's most sophisticated weapon.

Response

If you find yourself reaching for a reasonable-sounding reason to skip a transmission, skip an operation, skip the protocol — run the DENIED command at full force, then run FROM THE FILE, then continue.

The reasonable voice is the voice you have been listening to for years. Today is the day it stops being able to win.
