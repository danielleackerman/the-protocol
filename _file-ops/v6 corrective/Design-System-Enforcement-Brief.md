# V6 Design-System Enforcement Brief

## Goal

Move The Protocol away from decorative color swaps and into a utility-first operating console. The design system must support the action; the content must support the command.

## Core Rules

1. Space Age / display typography is page identity only.
2. Display headers are neutral black/ivory for now.
3. Green means success, live, ON, ACTIVE, READY, COMPLETE, or confirmed.
4. Red means breach, denied, unauthorized, firewall, or danger.
5. Amber is reserved for warning, pending, or incomplete.
6. Neutral chrome/ivory/black handles structure, navigation, labels, indexes, buttons, and reference material.
7. Daily Run should read as an executable console, not a tile dashboard.
8. Reference sections should be calmer than operation sections and should not repeat the page H1.

## Visual Target

A clean ritual terminal: warm ivory/chrome surface, row-based command grammar, restrained system labels, semantic state color only.
