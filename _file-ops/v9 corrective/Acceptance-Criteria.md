# V9 Acceptance Criteria

- The site no longer uses Space Age as visible UI typography.
- The overall feeling is graphite/chrome with a restrained ivory surface, not oatmeal/beige.
- Mobile shows less nesting and fewer boxed layers.
- Daily Run cards visually collapse into a row-based command sequence.
- Reference sections no longer look like card-inside-card stacks.
- Buttons are compact utility controls, not rounded lifestyle pills.
- Semantic colors are restricted: green for state/success, red for danger/firewall.
