# V9 Basic Utility Reset

## Goal

Strip the Protocol interface back to a plain utility system:

- no Space Age display typography
- no oatmeal-warm full-site wash
- graphite/chrome surface with a small ivory warming layer
- masculine, basic, functional controls
- semantic color only for state
- reference sections flattened instead of nested
- mobile-first density

## Rules

- Brand and H1 use the standard UI sans stack, not Space Age.
- Most UI is neutral graphite/chrome.
- Ivory is only a light warming surface, not the dominant visual identity.
- Cards are plain panels with squared utility radius.
- Buttons are compact controls, not pills.
- Daily Run reads as rows, not a dashboard grid.
- Reference sections flatten into simple blocks and rows.
- Green is only success/state. Red is only danger/firewall.
