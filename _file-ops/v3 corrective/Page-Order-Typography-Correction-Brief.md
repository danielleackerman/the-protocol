# V3 Page Order + Typography Correction Brief

## Problem

The multi-page redesign fixed architecture but some public pages still read like implementation notes, and level pages placed explanatory material before the actual command/action sequence. Migrated chamber text also retained inline label/value structures that collapsed visually on mobile.

## Correction

- Public pages must read as the Protocol, not a changelog about the Protocol.
- Each level page should surface the primary command/action panel first.
- Explication follows the action panel.
- Header brand must use the local display font.
- Mono/CLI hierarchy remains for labels, status text, command blocks, and utility navigation.

## Acceptance Criteria

- Level 01 shows Install Command Sequence before the explanatory cards.
- Overview no longer describes the site migration or accordion replacement.
- Bold labels and adjacent text no longer run together.
- Header brand uses the local Space Age display font when available.
