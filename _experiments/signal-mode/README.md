# Signal Mode Lab

This folder is for developing the v0-inspired Signal visual system without contaminating the production Utility design.

## Current rule

Utility is production.

Signal is experimental.

Do not connect Signal CSS or JS to the live site until the Signal skin is fully designed and reviewed.

## Goal

Develop two complete visual skins:

- Signal Dark
- Signal Light

These should preserve the current site structure while changing only the visual language.

## Files

- `README.md` — notes and design rules
- `signal-dark.css` — dark Signal skin draft
- `signal-light.css` — light Signal skin draft
- `signal-preview.html` — isolated preview page

## Extraction targets from v0

- dark signal background
- light signal/custom background
- panel surfaces
- gradients
- borders
- glow level
- nav/button treatment
- H1 treatment
- typography accents
