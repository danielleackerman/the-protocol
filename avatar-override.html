How the Override Runs

Avatar Override treats the lag between command and result as a sign that the wrong avatar is running — not as proof the result is far away. The run does not add effort. It deactivates the old file at the source, installs the new one, calibrates the channels that carry it, enters the code that normalizes the impossible, and locks. One pass, in order.
